# Leap of Faith

A 2D endless platformer built with Godot.

## About

Leap of Faith is a mobile game where you play as a frog climbing endlessly through a vibrant world of lily pads, insects, and environmental hazards.

## Features (Planned)

- Endless vertical platforming
- Physics-based jumping
- Multiple frog species
- Unlockable cosmetics
- Leaderboards
- Dynamic platform types

## Engine

- Godot 4
